# Riset AI News — Output Folder

Folder ini berisi brief harian hasil riset berita AI.

## Format Nama File

`YYYY-MM-DD.md` — contoh: `2026-06-13.md`

## Fungsi

- Satu file per hari
- Dipakai oleh skill untuk deduplication (cek berita kemarin sebelum mulai riset baru)
- Bahan baku carousel Instagram AIpreneur

Jangan hapus file lama — dibutuhkan untuk menghindari duplikasi konten.
